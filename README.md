# HA Guardian (Home Assistant add-on)

AI helper for Home Assistant: security monitor, device-health and internet alerts, camera person detection,
a Guardian dashboard, and a chat panel.

Install: Home Assistant > Settings > Apps > App store > three-dot menu > Repositories > add this repository's URL.
Then install **HA Guardian**, enter your Anthropic API key in its Configuration tab, and start it.

No secrets are stored in this repository. Your API key lives only in the add-on's options inside your Home Assistant.
